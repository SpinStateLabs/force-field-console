How it works

  1. 1

    Register & get an API key

    Create a console account and mint an ff_live_ key from the dashboard. The key is shown once at creation — the console stores only a hash.

  2. 2

    Register your agent & mint a scoped delegation

    Declare the agent's identity in the registry, then grant it a scoped delegation: what it may do, on whose behalf, and within what limits.

  3. 3

    Every action checked

    Each action is put to the sentinel and comes back ALLOW BLOCK ESCALATE — and everything is sealed in a hash-chained ledger.

One call to the sentinel

curl -X POST https://YOUR-CONSOLE-DOMAIN/api/v1/sentinel/check \
  -H "x-api-key: ff_live_YOUR_KEY" \
  -H "content-type: application/json" \
  -d '{"agent_id": "my-agent", "action": "example.action"}'

Illustrative request shape — see the repository for the sentinel's request schema. While no estate is attached to the gateway, /api/v1/* returns an honest 503 instead of a fabricated verdict.
